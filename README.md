# CodeAlpha_image_gallery

# Interactive Image Gallery 📸

## Description
This project is a responsive Image Gallery built as part of the **CodeAlpha Frontend Development Internship** (Task 1). It showcases a grid of images that can be viewed in a full-screen lightbox mode with navigation controls.

## Features
- **Responsive Grid:** Automatically adjusts layout for mobile, tablet, and desktop screens.
- **Lightbox Viewer:** Click any image to view it in full-screen mode.
- **Navigation Controls:** "Next" and "Previous" buttons to browse images within the lightbox.
- **Keyboard Support:** Navigate using Arrow keys and close using Escape.
- **Smooth Animations:** Hover effects and transitions for a polished user experience.

## Technologies Used
- HTML5
- CSS3 (Grid & Flexbox)
- JavaScript (DOM Manipulation)

## How to Run
1. Clone this repository or download the files.
2. Open `index.html` in your web browser.
3. Click on images to test the lightbox functionality.
